# 一键推送脚本

脚本位置：

- `cmd_bat_sh/win10_cmd/push-all.bat`（Windows 双击/命令行入口）
- `cmd_bat_sh/win10_cmd/push-all.ps1`（PowerShell 实现）

作用：把当前工程 `develop` 一键提交并推送到：

- GitLab：`origin/develop`
- GitHub：`x469509136/qoder2api_panel_go` 的 `main`

## 用法

```bat
cmd_bat_sh\win10_cmd\push-all.bat
cmd_bat_sh\win10_cmd\push-all.bat "fix: 修复登录限速"
```

PowerShell 直接调用：

```powershell
.\cmd_bat_sh\win10_cmd\push-all.ps1
.\cmd_bat_sh\win10_cmd\push-all.ps1 -Message "fix: 修复登录限速"
.\cmd_bat_sh\win10_cmd\push-all.ps1 -SkipCommit
```

## 行为

1. 要求当前分支为 `develop`。
2. 工作区有改动时执行 `git add -A` + `git commit`；无改动时直接推送。
3. 推送 GitLab `origin/develop`。
4. 从系统 Git 凭据管理器读取 github.com token（不打印、不落盘、不写 remote），
   绕过本机 `gh-proxy` 重写，直接推送到 GitHub 主仓库 `main`。

## 前置条件

- VPN 已连接，且 `github.com:443` 可直连。
- 系统 Git 凭据管理器里 github.com 的 token 具备 `repo` 权限。
- GitLab remote `origin` 可正常推送。

## 退出码

- `0`：成功。
- `1`：任意步骤失败（脚本会在控制台打印 `[ERROR] ...`）。

## 安全说明

- GitHub token 只在 PowerShell 进程内使用，不会写入脚本、git remote、配置文件或日志。
- 脚本不会修改本地 `origin`；GitHub 推送使用一次性带 token 的 URL。
- 如需删除 `qoder2api_panel_go-git`，仍需带 `delete_repo` 权限的 token；本脚本不处理删除仓库。

如需临时改 GitHub 仓库（例如演练），可加：

```powershell
.\cmd_bat_sh\win10_cmd\push-all.ps1 -SkipCommit -GitHubRepo "https://github.com/其他账号/其他仓库.git" -GitHubBranch main
```
